# 🚗 Template V4 — เว็บไซต์ศูนย์ตรวจสภาพรถยนต์ (ตรอ.) ระดับพรีเมียม

พัฒนาต่อยอดจากแนวทางของ `Templatev3` ในโทนสี **ฟ้า-น้ำเงิน-เหลือง-ขาว** ที่สะอาด ทันสมัย น่าเชื่อถือ พร้อมยกระดับดีไซน์ ฟีเจอร์ และรูปภาพตัวอย่างใหม่ทั้งหมดแบบครบจบในแฟ้มเดียว (**Pure HTML + CSS + JS ไม่มี Framework ไม่ต้อง Build** เปิดไฟล์ `index.html` หรืออัปขึ้น Hosting / Netlify / GitHub Pages ได้ทันที!)

## ✨ จุดเด่นที่อัปเกรดขึ้นใน Template V4

1. **สถานะเปิด-ปิดร้านอัตโนมัติ (Live Open/Closed Pill)** — เช็กเวลาไทยจริง (จ–ส 08:00–17:00 น.) แสดงจุดไฟกระพริบสีเขียวเมื่อเปิดทำการ
2. **ระบบคำนวณค่าตรวจ + พ.ร.บ. เบื้องต้นแบบ Interactive** — ลูกค้าเลือกประเภทรถ (รย.1 / รย.2 / รย.3 / รย.12 แยกตาม CC) + ติ๊กบริการเสริม (ตรวจสภาพ / พ.ร.บ. / ฝากต่อภาษี / ตรวจแก๊ส) แล้วกด **คัดลอกรายการส่งจองทาง LINE** ได้ทันที!
3. **ขั้นตอนการใช้บริการ 3 ขั้นตอน + 5 ระบบตรวจเช็ก** — อธิบายเข้าใจง่ายใน 5 วินาที
4. **แกลเลอรีบรรยากาศร้านพร้อมระบบ Lightbox คลิกขยายดูรูปใหญ่** — พร้อมรูปตัวอย่างเจนใหม่ 5 รูป คมชัด ธีมตรงกับเว็บ ไร้ลิขสิทธิ์
5. **รีวิวลูกค้า + FAQ คำถามที่พบบ่อย** — ตอบคำถามยอดฮิต (รถกี่ปีต้องตรวจ, รถติดไฟแนนซ์ใช้สำเนาได้ไหม, ขาดต่อเกิน 1-3 ปีทำไง) ช่วยเพิ่มความน่าเชื่อถือและติด SEO ดีขึ้น
6. **แถบเมนูด่วนติดด้านล่างบนมือถือ (Mobile Sticky Bar)** — ปุ่ม `โทรเลย | แชท LINE | แผนที่` กดง่ายด้วยนิ้วโป้ง เพิ่มยอดลูกค้าโทรเข้าและทักแชท
7. **ชุดภาพตัวอย่างพร้อมโพสขายในโฟลเดอร์ `promo-post/`** — ทั้งภาพกราฟิกโปสเตอร์โพสขาย Facebook/IG/LINE และภาพแคปหน้าจอจริงครบทุกส่วน (Desktop + Mobile + Full Page)

## 🔧 คู่มือแก้ไขข้อมูลเพื่อส่งงานลูกค้า (ใช้เวลาไม่เกิน 5 นาที)

เปิดไฟล์ `index.html` แล้วค้นหาข้อความต่อไปนี้เพื่อแทนที่ด้วยข้อมูลร้านลูกค้า:

| ข้อมูลที่ต้องเปลี่ยน | ค่าตัวอย่างใน Template |
|---|---|
| **ชื่อร้าน** | `ตรอ. ออโต้เช็ค พลัส` |
| **เบอร์โทรแสดงผล** | `089-999-9999` |
| **ลิงก์โทรออก** | `tel:0899999999` |
| **LINE ID / ลิงก์ LINE** | `@tro-demo` และ `https://line.me/ti/p/~@tro-demo` |
| **ที่อยู่ร้าน** | `99/9 ถ.เพชรเกษม อ.สามพราน จ.นครปฐม` |
| **แผนที่ Google Maps** | ค้นหา `iframe` ด้านล่าง แล้ววาง Embed Code ของร้านลูกค้า |
| **ราคาฝากต่อภาษี / ตรวจแก๊ส** | แก้ที่ไฟล์ `script.js` ตัวแปร `TAX_SERVICE_FEE` และ `GAS_CHECK_FEE` |
| **รูปภาพร้านจริง** | นำรูปจริงมาวางทับในโฟลเดอร์ `images/` โดยใช้ชื่อไฟล์เดิมทั้ง 5 รูป |
